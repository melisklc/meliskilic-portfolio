02 · Key problems

Four gaps

The ads deliver the payoff in seconds. The app made people earn it, and pay for it, before they saw it.

Speed
7
screens before the first scan

Proof

03 · Design strategy
3.1.1 · ONBOARDING

Shorten the path to the first scan

7 screens delayed the first scan. The redesign removes the quiz and personalization steps, bringing the first scan into onboarding and closer to the ad promise.

CURRENT
REDESIGNED
3.1.2 · ONBOARDING

Reprioritize secondary features

The ads prioritize value, growth, and AI guidance, not collection management. The redesign brings those same priorities into onboarding.

3.2.1 · PAYWALL

Prove value before asking people to pay

The first result is free. The paywall comes after value, when users want more detail or another scan.

3.2.2 · PAYWALL

Reframe the paywall around core value

The original paywall focused on broad features and pricing. I reframed it around the value users came for and added a monthly tier to make the plans easier to compare.

CURRENT
REDESIGNED
3.3 · CORE FEATURE

Strengthen the result experience

The redesign makes grading and valuation clearer and more credible, with a familiar 1–10 score, stronger value hierarchy, recent sales, and source-backed evidence.

Personalization only where it adds value

The quiz wasn’t used meaningfully later, so it only added friction. Removing it keeps onboarding focused on scanning.

The first scan becomes the CTA

Onboarding now ends with a clear “Scan your first card for free” action instead of making users search for the camera.

Prove value before payment

The old flow showed a paywall immediately after scanning. The redesign gives users one real free scan first, matching the ad promise.

Intent opens the paywall

A free summary proves the product works. The paywall appears only when users ask for deeper proof or another scan.

07 · Expected impact

Five hypotheses

This is a concept, so these are bets to test, not results. Each one comes with the signal I’d measure.

Metric
Expected impact
What I’d measure
Activation
Shortens time-to-first-scan, helping more users reach core value in their first session.
% of installs completing a first scan · time from install to first value
Trial starts
A paywall that follows a real result converts better than a cold one.
Paywall view → trial start, split by trigger
Trial-to-paid

Trial → paid conversion · cancellations during trial
Engagement

Scans per user in week one · cards added to collection · D7 retention
Trust
Showing confidence and named sources reduces doubt about accuracy.

Deep violet-to-black backgrounds echo the reflective feel of foil/holo cards.

A consistent violet → blue gradient connects buttons, progress, pills, charts, and key interactions.

Frosted-glass surfaces and subtle luminous borders create depth without overwhelming the UI.

Glowing scan lines and corner brackets visually signal that the AI is actively analyzing the card.
